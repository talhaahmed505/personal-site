Network Engineering Fundamentals

Overview

A semester-long lab sequence from CNIT 344 at Purdue that walked through building a production-style network from scratch. Starting with a single router, the topology grew progressively more complex — Layer 2 redundancy, then dynamic Layer 3 routing — using a mix of VyOS, Cisco, and Aruba hardware.

What I built
  • Configured a VyOS router with inter-VLAN routing, NAT for internet access, and DHCP pools for each VLAN.
  • Designed and implemented a redundant Layer 2 topology across Cisco and Aruba switches, using Multiple Spanning Tree Protocol (MSTP) to prevent loops while maintaining redundant paths.
  • Configured 802.1Q trunk links and access ports across all switches, mapping VLANs to the correct segments.
  • Migrated from static routing to OSPF, configuring areas and verifying neighbor adjacencies and route propagation across the full topology.
  • Tested failover by pulling links and confirming MSTP reconverged and OSPF re-routed traffic correctly.
What I learned

Building the same network in stages — routing first, then L2 redundancy, then dynamic routing — made the interactions between layers concrete rather than theoretical. Debugging MSTP port states and OSPF neighbor adjacency issues hands-on was the most valuable part, since it mirrors the kind of troubleshooting required on real enterprise gear.
