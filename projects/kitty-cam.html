Kitty Cam

Overview

A live PTZ camera stream that lets me watch my cat from anywhere, built around a network-isolated Raspberry Pi. The Pi acts as a wireless router, firewall, and compute node simultaneously — the camera's traffic never reaches the main home LAN.

The streaming backend is written in Python and packaged as a Docker container, using WebRTC for real-time, low-latency video delivery.

What I built
  • Configured the Raspberry Pi as a wireless access point (hostapd) with a dedicated SSID for the camera, isolated from the rest of the home network via firewall rules (nftables).
  • Set up the Pi as the router for the camera subnet so all traffic is inspected and controlled before it can reach anything else.
  • Wrote a Python application using WebRTC (aiortc) to capture the PTZ camera feed and stream it with sub-second latency to a browser.
  • Packaged the application in a Docker container for easy updates and restarts.
  • Implemented PTZ control commands (pan, tilt, zoom) via a simple web UI served alongside the stream.
What I learned

Designing a multi-role Pi (AP + router + firewall + compute) forced me to think carefully about traffic flows and how to write tight firewall rules that allow only exactly what is needed. Working with WebRTC and aiortc deepened my understanding of ICE, STUN, and how real-time media negotiation works under the hood.
