Unity VR Game

Overview

A team project from TECH 120 at Purdue. Our group of six designed and built a VR game in Unity intended to teach geometry concepts to elementary-school-aged children, using interactive 3D environments to make abstract shapes tangible.

What I built
  • Collaborated in a team of six using Unity and C# to build a complete VR experience targeting Meta Quest hardware.
  • Implemented interactive geometry puzzles where players manipulate 3D shapes to match targets.
  • Wrote C# scripts to handle VR controller input, object physics interactions, and scene transitions.
  • Coordinated with teammates using Git for version control and regular playtesting sessions to iterate on the design.
  • Presented the finished game to the class as a demo with playable levels.
What I learned

This was my first serious team software project. Learning to coordinate code changes across six people — managing merge conflicts, agreeing on scene ownership, and communicating design decisions — was as valuable as the Unity and C# skills themselves.
