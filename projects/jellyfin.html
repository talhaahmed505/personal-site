Jellyfin

Overview

Self-hosted media server running as a Docker container, accessible at jellyfin.talhaahmed.dev. It streams my personal video and music library from home storage to any device, exposed to the internet through a Cloudflare Tunnel so no inbound firewall ports are required.

What I built
  • Deployed Jellyfin in a Docker container with persistent volumes for config and media storage.
  • Configured a Cloudflare Tunnel to proxy traffic to the container without exposing my home IP or opening router ports.
  • Set up user accounts with separate library permissions for family access.
  • Organized media libraries with proper metadata scraping and artwork.
Tech stack
Personal Docker Cloudflare Tunnel Linux
