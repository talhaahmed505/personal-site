Active Directory & Virtualization

Overview

A two-part course project from CNIT 242 at Purdue. The first half focused on building a multi-site Windows Active Directory environment from the ground up. The second half covered enterprise virtualization — migrating physical Windows servers onto a VMware ESXi cluster backed by a SAN.

What I built
  • Deployed a multi-site Active Directory domain with a primary domain controller and a secondary DC at a remote site, connected via a site link.
  • Created and enforced Group Policy Objects (GPOs) for password policy, desktop lockdown, and software restrictions across the domain.
  • Automated bulk user and group provisioning using PowerShell scripts.
  • Stood up a VMware ESXi cluster managed by vCenter, then migrated the physical AD servers onto virtual machines using cold migration.
  • Configured shared storage via a SAN for the ESXi cluster, enabling vMotion between hosts.
What I learned

This project gave me hands-on experience with enterprise Windows infrastructure at a scale that mirrors real deployments. Understanding how AD replication works between sites, how GPOs are scoped and inherited, and how to move workloads to virtualized infrastructure without downtime were the most valuable takeaways.
