Minesweeper

Overview

A faithful Java recreation of the classic Minesweeper game, built for CNIT 255 at Purdue. The project covered 2D array manipulation, recursive algorithms, and event-driven GUI programming in a single, self-contained application.

What I built
  • Modeled the game board as a 2D array of cell objects tracking mine status, revealed state, and neighbor mine count.
  • Implemented mine placement using random seeding with configurable board dimensions and mine density.
  • Wrote a recursive flood-fill reveal algorithm that automatically uncovers adjacent empty cells when a zero-count cell is clicked — the core mechanic of Minesweeper.
  • Built the Swing GUI with a grid of JButtons representing cells, updating visual state (numbers, flags, mines) on each click.
  • Handled right-click flagging, win detection (all non-mine cells revealed), and loss detection (mine clicked).
What I learned

The recursive flood-fill was the most interesting algorithmic challenge — getting the base cases right so it doesn't over-reveal or infinite-loop required careful thinking about the boundary conditions. It was a good introduction to graph traversal disguised as a game mechanic.
