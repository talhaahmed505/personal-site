Raspberry Pi RAID & LAMP Server

Overview

A CNIT 182 project that combined Linux software RAID with a full LAMP web server stack, all running on a Raspberry Pi. The twist: the RAID 1 array was built from two USB flash drives rather than traditional disks, making it a compact exercise in fault-tolerant storage.

What I built
  • Created a RAID 1 (mirroring) array using mdadm across two USB flash drives attached to the Pi.
  • Formatted the array and mounted it persistently via /etc/fstab.
  • Installed and configured Apache, MySQL, and PHP on Raspberry Pi OS.
  • Deployed a simple web application on the LAMP stack served from the RAID array.
  • Simulated a drive failure by unplugging one USB drive and confirmed the array degraded gracefully and continued serving the site.
  • Re-added the drive and monitored mdadm resync to full redundancy.
What I learned

Watching the array degrade and then resync in real time made RAID concepts much more concrete than reading about them. Understanding the mdadm state machine — active, degraded, recovering — and how the kernel handles writes during a resync was the key takeaway.
