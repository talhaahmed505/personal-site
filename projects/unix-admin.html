Unix Administration

Overview

Lab-based course (CNIT 340) covering Linux system administration topics that come up in real enterprise environments — from storage and printing to network file sharing, authentication, and mandatory access control.

What I built
  • Configured disk quotas for users and groups on ext4 and XFS filesystems.
  • Set up CUPS print server with shared printers accessible from Linux and Windows clients.
  • Configured PAM (Pluggable Authentication Modules) for custom login policies, including account lockout and two-factor requirements.
  • Deployed NFS and Samba shares with proper permission mappings between Unix and Windows clients.
  • Enabled X11 forwarding over SSH to run GUI applications remotely.
  • Wrote and enforced SELinux policies, troubleshooting AVC denials with audit2allow and restorecon.
What I learned

SELinux was the most challenging part — understanding that file contexts and process domains are separate from traditional Unix permissions, and learning to read audit logs to diagnose and fix policy denials without simply disabling enforcement.
